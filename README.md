# WithPaper · 纸间

面向日常办公的在线文档工具箱，让 PDF 处理、文字识别和批量操作在浏览器里完成。

WithPaper 支持 PDF 原文编辑与同步预览、PDF 转 Word、合并拆分、页面管理、图片与 PDF 互转、图片压缩缩放、照片扫描、中英文文字识别及批量处理。文件由用户设备上的浏览器处理，无需上传到服务器，也无需安装桌面软件。

## 项目特点

- **本地处理**：PDF、图片和识别内容均在浏览器内处理，结果通过浏览器下载。
- **原文编辑**：直接在 PDF 页面中修改支持的文字、图片和图形，右侧同步展示修改后的 PDF。
- **办公常用工具集中使用**：提供 17 个工具，覆盖文档整理、图片处理、扫描、内容提取和批量文件处理。
- **纯前端架构**：无需文件处理后端、数据库或 API 密钥，可部署到静态托管平台。
- **资源随站点提供**：PDF 引擎、OCR 模型、字体和 WebAssembly 文件随项目构建，不依赖第三方 CDN 完成文件处理。

## 图片压缩与转换

选择多张 JPG、PNG 或 WebP，设置输出格式、质量与宽高后预览或处理。保持比例时，单独填写宽度或高度会按比例缩放；同时填写则按比例放入指定范围。关闭保持比例可分别指定宽高。PNG 的质量滑块不影响其无损编码。透明区域在 PNG/WebP 中保留，转 JPG 时使用所选背景色。

可填写目标大小（整数 KB），工具优先降低 JPG/WebP 编码质量，再按比例缩小尺寸；PNG 主要通过缩小尺寸接近目标。因此目标大小可能改变填写的输出尺寸，极小目标不保证满足。结果显示实际尺寸、体积、相对原图的变化及是否达到目标。重新编码或转换格式也可能使文件变大；不承诺所有图片都能进一步压缩。

## 照片扫描成 PDF

支持上传多张图片，或在支持的手机浏览器中通过拍照入口添加照片。逐页框选纸张四角，可拖动、先选角再点击图片、使用方向键，或在“精确调整四角”中输入百分比坐标。通过透视变换将纸张拉正，支持 90° 旋转与原色、彩色文字增强、灰度、黑白模式，以及亮度、对比度调整。自动找边适合明亮纸张与较暗背景，复杂背景可能失败，需人工修正。

每页保存独立四角与旋转设置，滤镜和输出设置应用于所有页面；可以前移、后移或删除页面。预览最长边限制为 1400 像素，导出可选 1600/2400/3200 像素，不放大超过裁剪区域的原始细节。支持 A4 或适应图片的多页扫描 PDF，也可逐页输出 PNG/JPG 并打包下载。

选择“提取文字 TXT”或“可搜索 PDF”时复用本站中英文 OCR 模型。可搜索 PDF 保留扫描图像，在对应位置增加不可见 Unicode 文字层，可搜索和复制；它不会把表格变为原生单元格或把扫描件变成可直接编辑的原文 PDF。结果提示低置信度行、字体不支持的字符和空识别结果，姓名、金额、编号等仍需核对。拍糊、反光遮挡和严重阴影无法保证修复。

图片处理在可取消的本地 Worker 中执行，需要支持 OffscreenCanvas、createImageBitmap 的现代浏览器。单张输入上限为 6400 万像素，普通图片缩放输出上限为 3200 万像素；这些是保护上限，实际可处理大小取决于设备内存，手机建议分批操作。相机入口是否打开相机由设备和浏览器决定；当前不支持 HEIC、动画保留、PDF/A 或数字证书签名。

## PDF 转 Word

选择 PDF 后，可指定页面范围、扫描识别方式及语言，导出 `.docx` 文件；多文件提供逐个下载和 ZIP 打包。原生 PDF 优先直接提取文字，避免 OCR 引入错字；没有可用文字的页面自动使用本地中英文 OCR。图文混合页可选“同时识别图片内文字”。

转换优先保持原页尺寸、分页和文字位置。文字以定位文本框保存，可以在 Word/WPS 中编辑；图形、插图和表格边框以背景图片保留，表格不会自动重建成 Word 单元格，段落也不会像原生 Word 文档一样整体重排。字号、颜色和粗斜体尽量保留；未嵌入 PDF 原字体，查看设备缺少字体时会替换。扫描识别和复杂排版需人工核对，低置信度识别会在结果说明中提示。

不调用云端转换服务，文件和识别结果不会上传。受 Word 页面尺寸限制，最长边超过 55.88 厘米的页面需先调整尺寸。

## PDF 原文编辑


编辑器左右两侧均显示 PDF 页面：左侧用于编辑，右侧展示实际修改后的文件。

1. 打开“编辑 PDF”并选择文件。
2. 在左侧页面点击需要修改的文字，直接在原位置输入；选中图片或图形后，通过工具栏执行对应操作。
3. 需要补充内容时，选中文字并点击“在此段下新增”，输入新的段落。
4. 在右侧检查修改效果；可使用定位、缩放、撤销和重做辅助核对。
5. 预览更新完成后下载，导出的文件与右侧预览使用同一份 PDF 数据。

新增段落支持中文、换行、字号、颜色、间距和水平偏移。编辑器修改 PDF 中的原内容对象；新增及替换后的文字仍为可复制、可搜索的原生文字。

**编辑范围与限制：**

- 当前采用原位置编辑，不支持 Word 式自动排版。新增或加长文字不会自动下移后续内容，也不会跨页重排，请在预览中检查重叠情况。
- 优先复用原字体；原字体缺少所需字符时，会使用内置中文字体并提示，字体外观和文件大小可能变化。
- 扫描图片中的文字不能直接作为原文字编辑，可使用 OCR 工具提取文本；扫描图片本身可替换。
- 嵌套 Form XObject 和部分特殊绘图对象当前只读。

## 文件隐私与运行方式

选择文件后，处理工作在浏览器中执行，应用不将文件内容上传到服务器，也不会直接修改磁盘上的原文件。需要保留处理结果时，请主动下载。

访问网站时，浏览器仍需从部署站点加载页面、脚本、字体和识别模型；这些资源请求与上传用户文件是不同的。首次打开 OCR 或 PDF 编辑功能时，资源加载可能需要一些时间。

完整功能应通过 **HTTP 或 HTTPS** 访问。直接双击 `index.html` 不能保证所有工具正常运行，也不代表网站支持完整离线使用。刷新或关闭页面会丢弃未下载的处理结果。

## 本地运行

### 环境要求

- Node.js **24.x**，版本要求见 `package.json`。
- npm，用于安装依赖和执行构建。
- 支持 WebAssembly 与 Web Worker 的现代浏览器。
- Python 3，仅用于下面的本地静态预览命令；也可以替换为其他静态文件服务器。

在项目根目录执行：

```sh
npm ci
npm run build
python -m http.server 4186 --bind 127.0.0.1 --directory dist
```

打开 <http://127.0.0.1:4186> 即可使用。

`npm run build` 会构建本地处理引擎、字体和模型资源，并将网站运行文件输出到 `dist/`。本地预览服务器仅提供静态文件，不负责处理 PDF、图片或 OCR 任务。

修改源码后，重新执行 `npm run build`，再刷新预览页面。

## 使用提示与已知限制

- **页码范围**：支持 `1-3,5` 等格式；旋转和提取时留空表示全部页面。重新排序需要包含全部页面，且不能重复。
- **水印移除**：仅支持标准 `/Watermark` 批注，以及本工具写入并单独标记的水印内容流。不支持修复已经融入图片的水印，也不会自动删除无法识别的正文内容。
- **特殊 PDF**：暂不支持加密 PDF、交互表单及签名字段。合并、提取和重新排序页面不保留原文档书签。
- **OCR 准确率**：当前提供简体中文和英文模型，识别效果受清晰度、字体与版式影响，结果需人工核对。编辑后下载的“当前 TXT”包含修改，下方逐页文件保留原始识别文本。
- **设备性能**：大文件、高分辨率图片和大量页面会消耗更多内存，处理速度取决于用户设备。
- **暂未提供**：PDF 压缩、PDF 转 Excel/PowerPoint，以及 Word、Excel、PowerPoint 转 PDF。

安装依赖后执行：

## 支持作者收款码配置

页脚和工具结果区提供自愿支持入口。将真实收款码图片放入 `assets/support/`，例如 `wechat.png` 和 `alipay.png`，然后在 `app.js` 的 `supportMethods` 中，将对应 `image` 从空字符串改为 `assets/support/wechat.png` 或 `assets/support/alipay.png`。重新执行 `npm run build` 并部署 `dist/`，图片会随网站发布。

未配置或加载失败的支付方式显示“收款码暂未开放”。此功能只展示收款码、提供图片保存，不自动判断付款成功，也不限制免费工具使用。
